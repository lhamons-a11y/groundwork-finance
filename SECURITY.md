# Reporting a security problem

Groundwork keeps a household's financial records, and some bank sign-in details, on the person's own computer.
A security problem in it matters, so please report one privately rather than in a public issue.

**Email:** support@groundworkfinance.app, with "Security" in the subject.

Please include what you found, how to reproduce it, and which version (Settings → About). Don't include anyone's
real financial data or passwords; made-up figures are enough.

You'll get a reply acknowledging the report. A fix ships in the next release, and the release notes credit you
unless you'd rather they didn't.

## What counts

- anything that sends a person's data off their computer that Groundwork's Privacy page doesn't say it sends
- reading the bank-login vault or an encrypted backup without its password or recovery key
- a page, file or import that makes Groundwork run code, or change data, without the person asking
- the local server answering requests from other programs or web pages without its token
